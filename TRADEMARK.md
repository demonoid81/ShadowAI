The name **ShadowAI** and the ShadowAI logo (collectively, the

This document describes how the ShadowAI Marks may be used.

The Apache License 2.0 that covers ShadowAI Core does **not** grant
trademark rights (see Section 6 of the Apache License). Permission to
use the ShadowAI Marks is governed exclusively by this document.

## Summary

- You **may** use "ShadowAI" to refer truthfully to the ShadowAI
  project, its software, and its documentation.
- You **may** fork the source code under the Apache License.
- You **may not** use "ShadowAI" as part of the name of a fork, a
  hosted service, a commercial product, or anything that could
  reasonably create confusion about the origin of that offering.
- Use of the ShadowAI logo requires prior written permission.

The goal is simple: readers and buyers should always be able to trust
that "ShadowAI" refers to the software produced by the project
maintainers, and not to a third-party modification or hosted service.

## Permitted uses (no prior permission required)

You may use the name "ShadowAI" without prior permission in any of the
following contexts, provided the use is truthful and does not suggest
endorsement:

1. Referring to the project in articles, blog posts, presentations, and
   academic works.
2. Stating that your software is "compatible with ShadowAI" or
   "built on ShadowAI" when that is factually accurate.
3. Describing a downstream package (for example, a Linux distribution
   package) as "ShadowAI" when it is an unmodified redistribution of
   Core with only packaging changes required by the distribution.
4. Internal use within your organization (for example, naming a
   deployment "team-alpha-shadowai-prod").

## Uses requiring prior written permission

Each of the following uses requires prior written permission from the
ShadowAI maintainers:

1. Using "ShadowAI" (or any variant that includes "Shadow AI",
   "ShadowAi", "shadow-ai", etc.) as part of the name of a product,
   service, company, domain, or project you distribute publicly.
2. Using "ShadowAI" in the name of a paid hosted service that provides
   ShadowAI functionality (managed SaaS, cloud offering, etc.).
3. Using the ShadowAI logo in any form, including modified versions.
4. Using "ShadowAI" in a way that suggests official endorsement,
   partnership, or certification.

## Explicitly prohibited uses

The following uses are prohibited and will be treated as trademark
infringement regardless of any open-source license grant:

- Offering a modified fork of ShadowAI under the name "ShadowAI" (use
  a different name, e.g., "AcmeGuard, based on ShadowAI").
- Operating a managed hosted service under a name that includes
  "ShadowAI" without a written agreement.
- Using the ShadowAI logo in a way that implies endorsement of your
  unaffiliated product or service.
- Registering a domain that uses "ShadowAI" in a manner likely to
  confuse users.

## Forks

Forks are welcome under the Apache License. Please rename your fork so
it is clear the fork is not the official ShadowAI. A common pattern is:

- **OK**: "AcmeGuard — a fork of ShadowAI maintained by Acme Corp."
- **Not OK**: "ShadowAI Pro by Acme Corp."

## Commercial use of the name

Commercial use of the ShadowAI name in a product or service offering
requires a separate commercial trademark agreement. This is independent
of the source code license. Contact the maintainers to discuss terms.

## How to request permission

Open an issue titled `[trademark] <request>` describing the proposed
use, the scope (geography, duration, medium), and the entity making
the request. The maintainers will respond within a reasonable period.

For commercial/trademark agreements, use the same channel; discussion
may then move to a private thread.

## Updates to this policy

This trademark policy may be updated. Material changes will be
announced in `CHANGELOG.md`. Permissions already granted in writing
remain valid under the terms in force at the time of the grant.
